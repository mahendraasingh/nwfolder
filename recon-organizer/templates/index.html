/// Core Reconnaissance Capabilities

MODULE 01

IP Address Lookup

Resolves target domains to all associated IPv4 addresses, retrieves reverse DNS (PTR) pointers, canonical hostnames, and geographic routing metadata.

MODULE 02

DNS Records Lookup

Interrogates authoritative DNS nameservers for zone records including A, AAAA, MX (Mail Exchangers), NS (Nameservers), TXT (SPF/DMARC), and SOA records.

MODULE 03

WHOIS Registry Data

Queries top-level registries to inspect domain ownership timeline, sponsoring registrar, creation dates, expiration dates, domain statuses, and nameservers.

MODULE 04

SQLite Intelligence Log

Maintains a structured persistent database of previous searches, enabling retrospective analysis, trend comparisons, and raw JSON intelligence export.
